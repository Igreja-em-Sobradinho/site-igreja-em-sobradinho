# Projeto IGR - Site da Igreja

## Descrição

Este projeto é um site completo para igreja, desenvolvido com tecnologias modernas para facilitar a interação entre membros e administradores. O site permite visualizar eventos, organizar melhor os serviços - ministerios, galeria de fotos, e gerenciar conteúdo de forma segura, com autenticação de usuários.

## Funcionalidades

- **Página Inicial**: Apresentação da igreja e navegação principal.
- **Eventos**: Lista de eventos futuros e passados, com detalhes como data, local e descrição.
- **Galeria**: Exibição de fotos e imagens da comunidade.
- **Autenticação**: Login e registro de usuários (membro/admin).
- **Gerenciamento de Conteúdo**: Administradores podem criar e editar eventos e conteúdo.

- Acesse a página inicial para navegar.
- Faça login como membro ou admin para acessar funcionalidades restritas.
- Administradores podem gerenciar eventos via a API.
